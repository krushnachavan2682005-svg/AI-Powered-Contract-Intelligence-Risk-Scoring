# AI-Powered Contract Intelligence & Risk Scoring

An NLP platform for ingesting legal contracts, extracting entities and clauses, detecting risky language, and enabling semantic search.

## High-Level Goals

- **Automated Ingestion**: Support PDF and DOCX processing, including OCR.
- **Extraction & Classification**: Identify named entities and classify legal clauses using transformer models fine-tuned on datasets like CUAD.
- **Risk Scoring**: Generate explainable risk scores based on contract language.
- **Semantic Search**: Power natural language contract querying using vector embeddings.
- **Scalability**: Expose features via a robust, async FastAPI backend and containerized deployment.

## Current Development Status

**Current Stage**: Module 0 — Project Foundation

This project is being developed incrementally. Currently, only the foundational project infrastructure is established (configuration management, logging, base exceptions, and core project setup). Future ML and API features will be implemented module by module.
